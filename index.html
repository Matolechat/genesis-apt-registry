Installer Genesis sur Linux ou Termux.

Dépôts APT signés avec GPG, paquets vérifiables, client Python CLI. Version de préproduction 0.1.0~dev0-1.

Debian / Ubuntu Android Termux

Termux — première installation

Pour le Termux standard (préfixe /data/data/com.termux/files/usr). Ajouter la clé de dépôt et sa source une seule fois :

set -e
base="https://matolechat.github.io/genesis-apt-registry"
mkdir -p "$PREFIX/etc/apt/keyrings"
curl -fsSL "$base/genesis-archive-keyring.gpg" -o "$PREFIX/etc/apt/keyrings/genesis-archive-keyring.gpg"
echo "b05f7df0d0f719b87fd0f55544e1171aee887617d90aa55d02981cebb0354c7e  $PREFIX/etc/apt/keyrings/genesis-archive-keyring.gpg" | sha256sum -c -
echo "deb [signed-by=$PREFIX/etc/apt/keyrings/genesis-archive-keyring.gpg] $base/apt/termux stable main" > "$PREFIX/etc/apt/sources.list.d/genesis.list"
apt update
pkg install genesis
genesis --version

Debian / Ubuntu (amd64)

base="https://matolechat.github.io/genesis-apt-registry"
sudo install -d -m 755 /etc/apt/keyrings
curl -fsSL "$base/genesis-archive-keyring.gpg" | sudo tee /etc/apt/keyrings/genesis-archive-keyring.gpg >/dev/null
echo "b05f7df0d0f719b87fd0f55544e1171aee887617d90aa55d02981cebb0354c7e  /etc/apt/keyrings/genesis-archive-keyring.gpg" | sha256sum -c -
echo "deb [signed-by=/etc/apt/keyrings/genesis-archive-keyring.gpg] $base/apt/debian stable main" | sudo tee /etc/apt/sources.list.d/genesis.list
sudo apt update
sudo apt install genesis
genesis --version
